# AI Image Prompt Library

> A practical collection of reusable image prompts, custom slash-command combinations, creative workflows and learning resources.

**Updated:** 30 October 2026  
**Important:** Slash combinations in this repository are descriptive shortcuts, not native commands recognized by every AI image generator. Copy the full prompt and replace placeholders. Some platforms support their own separate syntax.

## Start here

1. Pick a category below.
2. Replace placeholders such as `[PRODUCT]`, `[SUBJECT]`, `[BRAND]`, `[REFERENCE IMAGE]` and `[ASPECT RATIO]`.
3. Copy the full prompt into your preferred image generator.
4. Provide reference images for accurate products, people, typography or packaging.
5. Review results for factual, anatomical, text and brand accuracy.

## Prompt formula

```text
Subject + intent + environment + composition + lighting + material + camera + palette + output ratio + constraints
```

**Example:** Photograph [PRODUCT] for a premium launch campaign on a textured limestone pedestal, with warm side lighting, a three-quarter camera angle, accurate packaging, subtle contact shadows, a 4:5 portrait crop and no invented text.

## Key limitations

- A prompt cannot guarantee exact logos, labels, small text, product dimensions or scientific accuracy.
- Use approved source assets for regulated claims, medical visuals and before-and-after comparisons.
- Different models interpret the same instructions differently. Iterate and verify.
- Generated images are not evidence of real events or product performance.
