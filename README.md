# AI Image Prompt Library

**Updated:** 30 October 2026

A practical, expandable library for AI product photography, advertising, ecommerce, brand campaigns, creative testing and image production. Includes custom slash commands, combination shortcuts, prompt templates, industry recipes, production workflows and clean resource links.

> **Syntax notice:** Slash codes below are a personal shorthand system, not universal native commands. Expand them into natural-language instructions before pasting into an image tool. Tool-specific parameters differ. Never assume `/ar`, `/style` or other codes are accepted by every platform.

## Quick start

1. Upload an accurate reference photo of the actual product, preferably front, side, back and detail views.
2. Choose a product, intent, style, camera, light, placement and quality-control code.
3. Combine the codes using the formula below.
4. Expand the combination into a complete prompt using the master template.
5. Generate multiple concepts, inspect product accuracy and select an approved result.
6. Adapt for channels, add verified copy in a design editor when necessary, and export.

## Master combination formula

```text
/subject + /goal + /scene + /style + /light + /camera + /composition + /format + /preserve + /qc
```

**Example combination:** `/skincare + /hero + /marble + /luxury + /softbox + /macro + /center + /4x5 + /label-lock + /qa`

**Expanded example:** Create a premium 4:5 skincare serum advertising photograph using the supplied product image. Place the exact bottle on a pale marble pedestal. Use controlled softbox lighting, an elegant luxury editorial look, close-up camera framing, balanced negative space for a headline and physically believable contact shadows. Preserve the bottle geometry, cap, label, colors and all visible text exactly. Do not invent ingredients, claims, logos or product features. Inspect typography, reflections, scale and edge quality.

## Master production prompt

```text
ROLE: Commercial photographer and advertising art director.
OBJECTIVE: [awareness / consideration / conversion / retention]
PRODUCT: [exact product and reference images]
AUDIENCE: [persona, market and use context]
VISUAL STORY: [one specific message]
SCENE: [surface, setting, props and season]
COMPOSITION: [angle, crop, focal point, safe zones]
CAMERA: [lens, perspective, depth of field]
LIGHTING: [source, direction, softness, color temperature]
STYLE: [reference mood, brand palette, texture]
DELIVERABLE: [platform, aspect ratio, size, file requirements]
PRESERVE: [shape, label, color, material, features, proportions]
EXCLUDE: [invented claims, extra objects, distorted anatomy, watermarks]
REVIEW: Compare output to reference and report any uncertainty.
```

## End-to-end product image workflow

### Phase 1: Brief and product truth

Record the SKU, reference photos, exact label copy, approved colors, physical dimensions, permitted claims, target audience, campaign goal, rights and channel requirements. Mark which attributes must never change.

### Phase 2: Creative direction

Build three different concepts per audience: clean functional, emotional lifestyle and distinctive editorial. Write one visual promise per concept. Choose an explicit art direction, not vague instructions such as “make it better.”

### Phase 3: Reference preparation

Use clear real photographs, preferably multiple angles. Crop distracting backgrounds but do not erase actual product features. Separate source product imagery from inspiration images. For product truth, prioritize real references over model invention.

### Phase 4: First generation

Start with a clean packshot, then generate the hero scene. Specify object count, proportions, perspective, material, shadow behavior, lighting, negative space and exact output crop. Generate a small batch with one major change at a time.

### Phase 5: Quality control

Check shape, logo, label spelling, ingredient claims, materials, dimensions, colors, accessories, reflections, hands, shadows, perspective, text, cultural accuracy and regulatory restrictions. Reject invented product features. Compare every candidate side by side with the real product.

### Phase 6: Campaign expansion

Lock the approved product reference, palette, camera language and lighting style. Create distinct placements for social feed, story, display, website hero, email and marketplace. Reframe each layout rather than blindly cropping important elements.

### Phase 7: Creative experiments

Test one hypothesis at a time: background, benefit angle, audience context, focal length, lighting, color, prop or amount of negative space. Keep offer and audience constant where possible. Name variants consistently and measure actual performance, not aesthetics alone.

### Phase 8: Image-to-video

Prepare a stable hero image and a clean end frame. Write a motion brief covering camera movement, product movement, timing, physical plausibility and text overlays. Review every video frame for label drift, warped product geometry and unnatural movement.

### Phase 9: Export and governance

Keep source references, prompt versions, model/tool versions, approvals, export dimensions and license records. Confirm marketplace specifications and local disclosure rules. AI-generated visuals must not imply unverified medical, financial, performance or environmental claims.

## Prompt repair shortcuts

- **Wrong label:** “Use the uploaded product image as the source of truth. Do not regenerate or reinterpret printed text. Composite approved label artwork if exact reproduction is not possible.”
- **Distorted shape:** “Lock the silhouette, aspect proportions, closure, handle and attachment points to the reference. Modify only the background.”
- **Plastic-looking materials:** “Match the real material's roughness, reflectance, microtexture and physically believable shadows.”
- **Too generic:** “Replace stock-style composition with one distinctive visual metaphor relevant to the product benefit, without inventing product claims.”
- **Weak ad hierarchy:** “Create one clear focal point and reserve a clean area for approved headline and CTA overlays.”
- **Inconsistent campaign:** “Match the approved reference's camera height, lighting direction, palette, prop language and product scale across the set.”
- **Wrong crop:** “Recompose for [ASPECT RATIO], keeping product, important details and text-safe region fully inside the frame.”
- **Fake feature:** “Remove the invented feature and use only details visible in approved source photographs.”
